🧠 Algorithms Explained
📥

First Come First Serve (FCFS)

Non-Preemptive

Processes execute in the exact order they arrive in the ready queue.

⚡

Shortest Job First (SJF)

Non-Preemptive

The arrived process with the shortest burst time is selected to run next.

🔄

Shortest Remaining Time First (SRTF)

Preemptive

The running process is preempted if a newly arrived process has a shorter burst time than the remaining burst time.

🔁

Round Robin (RR)

Preemptive

Each process receives a fixed time quantum. If it doesn't finish within that time, it is moved to the end of the queue.

🥇

Priority Scheduling (Non-Preemptive)

Non-Preemptive

Each process is assigned a priority number. The highest-priority available process runs to completion.

🚨

Priority Scheduling (Preemptive)

Preemptive

Like priority scheduling, but the CPU can be immediately preempted when a higher-priority process arrives.

📊 Quick Comparison
Algorithm Type Avg Waiting Time Starvation Risk Best Use Case
FCFS Non-Preemptive High None Simple batch systems
SJF Non-Preemptive Low–Medium Possible Known burst-time environments
SRTF Preemptive Minimum Possible Optimal performance scenarios
Round Robin Preemptive Medium None Time-sharing & interactive systems
Priority (NP) Non-Preemptive Medium High Task-prioritized batch systems
Priority (P) Preemptive Low–Medium High Real-time & embedded systems
